# 八角录屏 · 完整功能与边界

> README 首页的详细版：完整功能清单、使用步骤、权限与当前边界。
> 首页见 [README.md](../README.md)。

## 已经实现

- 录制整屏、指定窗口或自定义区域（30 / 60 fps，1080p 或原始分辨率）
- 区域框选支持拖动内部移动、拖四角 / 四边缩放，`Enter` 或双击确认，
  `Esc` 或取消按钮退出；重新框选会带上上次区域，也可以一键清除
- 录制工作台：左侧展示所选屏幕、窗口或区域的静态来源预览，右侧集中来源、
  镜头与声音和高级选项；“开始录制”固定在页面底部。无屏幕录制权限时，
  来源预览上方直接显示引导卡，一键打开系统设置并可重新检查，不用等点
  “开始录制”才报错
- 独立窗口选择器：默认列出所有 macOS 桌面的窗口（其他桌面或最小化的窗口
  标注“当前不可见”，可切换“仅当前桌面”），按显示器分组和筛选，支持搜索
  应用、窗口标题或显示器名；列表显示应用图标、尺寸和所在屏幕，确认前可
  查看选中窗口大图
- 录制中可暂停 / 继续，暂停区间不会进入成片；屏幕、音频、摄像头和光标
  使用同一会话时钟
- 录制时菜单栏出现红色录制图标，点按即可暂停 / 继续、打标记、停止；
  不依赖 HUD 悬浮条，也不需要把主窗口带回前台
- 录制标记可从 HUD 或 `M` 创建，停止后可在时间线标尺和检查器中跳转、改名
- 同时录制麦克风和系统声音（可分别关闭，麦克风可选输入设备）；
  录制工作台与录制中 HUD 均显示输入电平，前 15 秒内麦克风持续静音
  会一次性提示
- 摄像头单独录制，支持 720p / 1080p 和设备选择
- 摄像头九宫格位置、自由拖动、四角缩放、方向键微调，以及方形、圆形、
  圆角矩形
- 六个构图预设：纯画面、角落讲解、圆形主讲师、并排讲解、竖屏上下、
  纯摄像头；有摄像头的新录制默认使用“角落讲解”
- 拖动时吸附九宫格和画布安全边距，也可直接输入位置和大小
- 画面加摄像头、只有画面、只有摄像头、并排四种布局
- 摄像头支持填满 / 完整显示、裁剪焦点、独立边框颜色 / 宽度和默认关闭的阴影
- 摄像头绿幕抠像：可选幕布颜色或从当前帧自动取色（多点采样估计
  背景色场，处理阴影与明暗不均，预览小图可见），调整颜色容差、边缘
  柔化、哑光内收、边缘羽化和去绿溢色，并提供影棚纯色幕 / 家用皱褶幕 /
  阴影重幕三套成套预设；新增「边缘光包裹」滑杆（默认 25%，0 = 关闭），
  让背景光沿人物边缘叠回前景，减少贴纸感；也可切换为自动分割模式
  （本机 Vision 人像遮罩，背景透明或重模糊）；原始 `camera.mov` 不改写，
  预览、MP4 和 GIF 共用同一合成结果
- 摄像头布局可按时间分段，在播放头切换布局、显隐或预览时自动生成新段；
  支持 0.3 / 0.5 / 0.8 秒平滑过渡
- 点击缩放时可自动缩小摄像头；若焦点仍被遮挡，会滑到最近的空闲角，
  退出缩放后平滑回位，也可独立关闭
- 新录制关闭系统光标烧录，单独保存光标轨迹；可调整大小、平滑、静止隐藏、
  隐藏延时和点击提示，预览 / 导出共用同一套渲染
- 记录左键点击位置，可绘制独立点击波纹
- 按键小条：录制偏好开启「记录按键」后，把按下的键以小条显示在
  画面左下角（最近 2.5 秒内的按键按时间排列）；只录修饰键组合与实体键，
  系统安全输入（密码框）期间整体跳过；数据只写本机工程文件，不上传；
  导出与预览一致
- 五轨时间线：视频、摄像头布局、缩放、声音、素材叠加（叠加轨无素材时
  隐藏）
- 素材叠加轨（画中画）：把图片或视频叠在主画面之上——画布拖动调位置
  （吸附与摄像头一致）、四角拖拽调大小、九宫格预设与大小滑杆；素材
  保存在工程目录内，精剪剪切时随区间自动裁剪平移；预览与 MP4/GIF/
  分段导出包含叠加效果（叠加在摄像头之上、打码与字幕之下），视频素材
  以自身时长起播、不混入素材音频
- 时间线轨道快捷入口：视频、摄像头、缩放、声音标题可点击和键盘聚焦，
  一次跳到对应页签与属性分组
- 编辑器固定工作区：预览和时间线不随右侧检查器滚动；中间主编辑区在三栏中
  优先且有保底高度，右栏内容再长或窗口再矮，预览也不被挤出视野；六个页签
  内按组折叠并显示当前摘要，摄像头页默认展开“当前构图”与“绿幕抠像”
- 视频片段可在播放头切分、删除并自动 ripple，也可拖动片段边缘修剪；
  支持 0.25×、0.5×、1×、1.5×、2×、4× 变速并保持音频音高
- 点击处自动平滑放大，可逐条启停
- 手动缩放区可添加、启停、调倍率、时长和焦点；手动区优先于点击建议
- 精剪页可扫描口播停顿 / 气口并给出候选（自然 / 紧凑两种节奏，可保护
  画面操作和系统声音），逐条试听、勾选后一键应用；一次应用只占一步撤销，
  摄像头布局、缩放区和字幕自动同步，原始素材不变
- 语音驱动摄像头：根据扫描到的语音活动，在 1.5 秒以上的长静默
  期间让摄像头平滑让出画面，下一段说话前提前恢复；只在没有手动布局段时
  生成，重复生成幂等替换，一次 ⌘Z 可全部恢复
- 口头禅与重说建议：只分析现有字幕（本机生成或导入 SRT），识别
  填充词、短窗口重复句和疑似重说；默认只建议不删除，低置信度不进入批量
  应用，重复句可“保留最后一遍”；应用复用停顿清理的原子剪切，全程不联网
- 长句内填充词：本机识别保留原始分段，除整条填充词外还能
  识别长句中间独立成词的「嗯 / 那个 / um」等（按置信度分高 / 低两档
  显示，勾选后实时显示预计剪掉秒数）；应用时字幕文本按分段边界手术
  重写——只删被选填充词及其后一个空白，重建校验不过的字幕（SRT 导入、
  术语表改写、手动字幕）文本原样保留，重写为空的片段随剪切删除，
  一次应用只占一步撤销且可完整还原
- 麦克风和系统声音可分别调整增益或静音，时间线显示基础波形
- 工程编辑支持 100 步撤销 / 重做；一次拖动或滑杆调整只占一步
- 横屏 16:9、竖屏 9:16 或原始比例画布
- 纯色、渐变或图片背景，以及留白、圆角、阴影；图片背景可选择本地图片，
  也可把当前系统壁纸作为静态快照复制进工程
- 实时预览画面、摄像头和放大效果
- 导出 H.264 / HEVC MP4，可选 720p / 1080p / 4K 和 30 / 60 fps；支持进度与取消
- 导出平台预设：一键套用「微信 / 文档 1080p30 H.264」「9:16 短视频」
  等组合（分辨率 / 帧率 / 编码 / 画布比例），填充后仍可逐项手调；
  上次选中项记在应用偏好里，不写入工程文件
- 导出前检查保存位置和可用空间；磁盘满、只读目录等失败会显示明确提示
- 手动字幕：播放头添加、逐条编辑起止时间、跳转和删除；可导入 / 导出 SRT，
  预览字幕并可选择烧录到 MP4，导出时自动写同名 `.srt` 旁车文件
- 字幕全文校对：字幕页可在「列表 / 全文校对」两种视图间切换；全文视图
  以文稿形式连续展示全部字幕，点时间码跳到对应起点，就地改字与列表页
  同源（字幕列表、SRT 导出、烧录预览、章节文本一致），播放推进时
  自动跟随滚动；回车在光标处拆条、清空即删条，均可一次 ⌘Z 还原
  （清空删条首次执行会弹确认，可勾选「不再提示」）；选中一段文本还能
  「删除选区片段」——连画面带字幕剪掉这段，走同一条
  原子剪切事务
- 本机离线字幕初稿：只在系统提供本机识别模型时使用，不切换云端；
  可从字幕生成合并短章节并导出章节文本
- 录制中断后启动应用会恢复已经落盘的视频和已有音频，并标记为“已恢复”
- 工程使用 Schema 5；旧工程自动迁移，保存时保留上一份可恢复版本
- 音频一键优化：自动电平（约 -14 LUFS 的 K 加权近似值）、人声增强、
  说话时自动压低系统声、轻量降噪与原声 A/B 试听；处理同时作用于预览
  与导出（同一条混合链），响度为近似值、增益由分析建议并经确认应用
- 定时区域打码：画布拖拽创建、时间线调起止，高斯模糊 / 马赛克，
  作用于最终输出像素（缩放后仍不可辨认，导出后不可逆）
- 字幕增强：术语表自动替换、三个样式预设、双语字幕（导入第二份
  SRT，不做机器翻译）、导出烧录模式（主 / 副 / 双）与可选章节标题卡
- 导出增强：只导出入出点区间（非破坏）、方形 1:1 画布、GIF 导出
  （控件收在导出卡「GIF 导出」折叠区，默认收起）
  （15fps，尺寸档位小 / 中 / 大 = 最长边 360 / 720 / 1080，默认中档
  720，体积估算随档位刷新并带长片警告）
- 按标记分段导出：导出卡「导出方式」三选一（整片 / 入出点 / 按标记
  分段，默认整片）；分段模式列出每段标记名、时间段与目标文件名
  （基名默认工程名可编辑，标记可勾选、默认全选），落在已剪除区间或
  片尾的标记列入跳过清单；逐段产出「基名-标记名.mp4」，重名标记自动
  加序号，目标文件夹已有同名文件时询问覆盖或新建子文件夹；导出中
  显示「第 N/M 段」，中途取消或失败时已完成段保留、可从失败段重试
  （GIF 导出不受分段影响，始终导出整片）
- 导出目录记忆：MP4 / GIF / SRT / 章节文本的保存面板默认打开上次导出
  成功的目录；该目录删除或不可写时回退工程目录
- 人脸居中（默认关）：Vision 本机检测生成裁剪焦点建议，审阅后应用，
  与语音显隐共用自动段机制
- 竖屏跟随（默认关，9:16 画布专用）：按人脸中心平滑平移竖屏取景的
  水平偏移（只平移不缩放），灵敏度慢 / 标准 / 快三档；多脸取最大脸、
  无脸回中、远距离移动限速平移；与人脸居中共用自动段机制，竖屏下
  冲突以竖屏跟随为准
- 工程管理：右键可“从列表移除”、归档到
  `~/Movies/八角录屏/Archive/` 或把完整工程目录移到废纸篓；支持
  `文件 > 导入工程…` 恢复归档工程。列表移除只写隐藏标记，不删素材
- 设置：`⌘,` 可选择 Delete 键默认动作、显示已移除工程、开启
  「Esc 停止前需确认」（默认关，开启后停止录制需 0.5 秒内二次确认），
  并打开归档目录或导入工程；完整删除始终二次确认
- 左栏折叠：在 228px 展开和 56px 折叠间切换，缩略图、选中态、提示
  和右键菜单在折叠态仍可用，状态跨启动保留
- 提词器面板：录制准备页右侧设置区「提词器」卡片（「来源」之后、首屏即可
  见）提供「输入/粘贴文稿」和「导入文件」入口，可粘贴 / 导入 `.txt` 与
  `.md` 文稿（上限 1 MB）；已设置时显示字数、首行预览和「清除」，未设置
  时显示引导文案，也可直接在面板打开状态下开始录制。字号 16–64pt、滚动
  速度 1–10 档可调，空格暂停 / 继续，进度条可拖回；文稿按空行分段，面板
  显示当前段与下一段预告，接近段尾自动减速。面板可拖动、默认靠近摄像头
  悬浮窗区域，位置 / 字号 / 速度按工程记忆恢复；面板窗口不共享内容且被
  录屏排除链覆盖，不会出现在整屏或窗口录像里。菜单「提词器」含快捷键，
  HUD 有提词按钮；不录制时打开即为预演模式。文稿随录制存入工程，旧工程
  自动回退默认
- 录制期摄像头悬浮窗：倒计时和录制时显示实时镜头，默认点击穿透；
  可进入调整模式拖动、四角缩放、九宫格吸附和切换圆角 / 圆形，停止录制
  后沿用同一构图。悬浮窗由现有 own-app exclusion 排除在录屏素材之外
- 构图预设作用范围：默认“从播放头生效”，也可“应用到全片”；手动
  预设立即切换、无过渡，并明确画布比例始终作用于全片。预设只改最终合成，
  原始 `camera.mov` 不变
- 界面为「图谱蓝线描」浅色体系：白底 + 蓝色线描，主色图谱蓝；陶橙只用于
  录制进行中的状态点与计时；外观锁定浅色，本轮不提供深色模式
- 工程与素材保存在 `~/Movies/八角录屏/`
- 全离线，不上传任何内容


## 使用

1. 双击 `八角录屏.app`。
2. 首次录制时，按 macOS 提示允许“屏幕录制”、 “麦克风”、可选的“摄像头”；
   使用本机字幕初稿时再允许“语音识别”。
3. 如果刚授权后没有画面，退出并重新打开应用。
4. 选择屏幕、窗口或区域，设置摄像头、画质和声音来源，点击“开始录制”。
5. 录制条出现在屏幕顶部。停止后自动进入编辑器。首次进入编辑器时顶部
   显示“三步出片”提示条，关闭后不再出现。
6. 在编辑器中切分片段、调整摄像头布局段、添加缩放区、平衡两路声音，
   按需导入 / 生成本机字幕，然后点击“导出 MP4”。

快捷键（应用内可在「帮助 > 键盘快捷键…」或按 `⌘/` 随时查看）：

- `⌘N`：新建录制
- `⌘⇧R`：开始 / 停止录制
- `⌘⇧P`：暂停 / 继续录制（录制中可用）
- `Esc`：停止录制（录制中，HUD 停止键；设置里可开启防误触二次确认）
- `⌘E`：导出 MP4
- `⌘,`：打开设置
- `⌘⇧O`：在访达中显示素材
- `⌘⇧I`：导入工程
- `⌘Z`：撤销工程编辑
- `⇧⌘Z`：重做工程编辑
- `空格`：播放 / 暂停
- `I` / `O`：把导出区间起点 / 终点设到播放头（导出「入出点」模式用）
- `⌘B`：在播放头切分当前视频片段
- `M`：在播放头添加录制标记
- 空格 / I / O / M 在编辑器内、非文本输入状态时生效
- `←` / `→`：步进播放头（默认 1 帧，按住 `⇧` 步进 1 秒）
- `⌥←→↑↓`：微调画中画摄像头位置（默认步进 1%，按住 `⇧` 步进 5%；
  仅画中画布局且已选中摄像头时生效）
- `⌘⌥T`：打开 / 关闭提词面板
- `⌘⌥P`：提词面板暂停 / 继续滚动（面板打开时）
- `⌘⌥↑` / `⌘⌥↓`：提词面板加速 / 减速一档（面板打开时）
- `⌘⌥←` / `⌘⌥→`：提词面板回退 / 前进一行（面板打开时）
- 提词面板获得焦点时，`空格` 直接暂停 / 继续滚动

## 权限

- 屏幕录制：`系统设置 › 隐私与安全性 › 屏幕与系统音频录制`
- 麦克风：`系统设置 › 隐私与安全性 › 麦克风`
- 摄像头：`系统设置 › 隐私与安全性 › 摄像头`
- 语音识别：仅在本机生成字幕初稿时请求；音频不离开电脑


## 当前边界

- 自动放大仍只针对左键点击；快速连点会合并成一个放大点。
- 本机字幕初稿依赖 macOS 当前语言包和语音识别授权；不可用时只提示并退回
  SRT 导入，不会联网。自动字幕默认优先识别麦克风轨。生成过程可随时点
  「取消」中断（识别阶段即时终止，音频组装阶段界面先退出等待态）；进度
  百分比随识别分段推进显示，部分语言模型不吐分段时只显示转圈与状态行。
- 本机识别对长时间前置静音可能直接返回“无可识别语音”；剪到有效口播段后
  已实际生成字幕，失败时仍可改用 SRT。
- 精剪模式和保护开关已持久化进工程；候选结果仍是会话数据，时间线
  改变后需重新扫描（会明确提示）。口头禅建议当前只处理整条字幕为填充词，
  或相邻字幕能判定的重复 / 重开，不分析长句中间的填充词。
- 语音驱动摄像头与人脸居中依赖摄像头轨分析结果；已有手动摄像头布局段时
  不会自动覆盖。两者共用自动段位，后应用的会整体替换先前的自动段。
- 章节由字幕合并生成；当前不写入 MP4 容器章节元数据（AVFoundation 公开
  API 无法可靠写出 text 轨），章节文本
  导出与旁车 SRT 不受影响。
- 音频优化的响度为 K 加权近似值（非认证 LUFS）；处理缓存放在系统临时
  目录，预览在缓存未就绪时先播原始音轨。
- 人脸居中的真机检出率与构图效果、音频处理的真人试听仍属发布前人工
  回归项。
- 录制期悬浮窗首版只支持画中画；并排讲解和竖屏上下仍在编辑器中应用。
- 窗口选择器默认枚举所有 macOS 桌面的窗口，其他桌面或最小化的窗口会标注
  “当前不可见”，可用“仅当前桌面”过滤；窗口在录制前被关闭或系统拒绝返回时
  仍需重新选择。最小化窗口可能能选中但取不到画面，应用会按流错误提示。
- “系统壁纸…”读取每块屏当前使用的静态图片并复制为工程快照，不是动态
  壁纸播放，也不是完整的内置壁纸图库；系统之后更换壁纸不会改写旧工程。
- 绿幕抠像只作用于摄像头轨；背景色场从单帧边框估计，取色时画面边框
  应为幕布（人物贴满边框时色场会被污染，可重估）。无绿幕的自动分割
  模式依赖本机 Vision 人像检测，逐帧执行使预览 / 导出明显变慢。真实
  头发边缘、半透明物体、强烈绿溢色与真人检出率仍需用实际摄像头素材
  做发布前质量复核。
- 提词器为手动滚动：不做语音跟随滚动、云端文稿与 AI 改稿；文稿导入上限
  1 MB；面板快捷键使用 `⌘⌥` 前缀，避免与文本输入（Option 特殊字符）冲突。
  面板在录制准备页打开后进入录制会保持显示；在编辑器中选中其他工程时会
  自动关闭。
- iPhone 录制和云端分享仍未实现。
- 全部主要功能与摄像头绿幕抠像已完成自动测试与打包构建；逐条试听 10 个以上
  切点、全片人工听音、真实摄像头人脸居中 / 绿幕边缘效果和本机语音拒绝
  分支仍属于发布前质量回归。
