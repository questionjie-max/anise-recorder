全部功能（多轨时间线、智能精剪、语音驱动摄像头、音频优化、定时打码、字幕增强、
构图预设、工程隐藏 / 归档 / 导入 / 删除、提词器、绿幕抠像等）已实现并纳入自动
测试。无法自动化的系统权限、真实摄像头 / 绿幕与真机录制项，见下方手动验收清单。

## 自动测试

运行全部测试：

```bash
swift test
```

### 串行与并行测试模式

导出类测试较多，按类分进程的并行模式更快也更稳，作为默认门禁：

```bash
swift test --parallel
```

早期串行单进程曾出现系统框架（`MediaToolbox` /
`AVAssetReaderOutput.copyNextSampleBuffer`）随机 `SIGSEGV`；根因是导出取消时
`AVAssetWriterInput.append` 与 `cancelWriting` 并发访问的竞争，已修复。修复后
的串行全量与导出密集子集多轮实证未再复现，崩溃点是受害者而非根因。

长测管理：

- 触发方式：环境变量 `ANISE_RECORDER_LONG_EXPORT=1`（代码依据
  `AniseRecorderTests.swift` 的 `testTenMinuteProjectExport` 入口跳过判断）；
  普通全量跑（串行或 `--parallel`）都会自动跳过，不占用门禁时长。
- 预期时长：整个测试约 100 秒，其中 10 分钟工程的真实 H.264 编码约
  88–89 秒；Debug 构建下整体明显慢于 Release，建议在缓存全热的构建后
  单独运行。
- 发布或导出链路大改后至少显式跑一轮；历史实测视频轨 / 音频轨均为
  600.000 秒、音画漂移 0.0 ms。

测试会在 `~/Movies/八角录屏/` 下创建唯一命名的临时工程，并在 `defer`
中删除。若测试进程被强制中断，可能留下 `test-export-*` 目录，确认无用后可
手动清理。

已知间歇性 flake：全量并行跑时间歇出现在
`testCancelledExportKeepsExistingFileAndRemovesTemporaryFile`（真实
AVFoundation 导出 + 取消用例）子进程 SIGSEGV，约三成一概率；单独复跑通过，
遇到时原样重跑全量即可，后续可考虑给该用例加串行隔离。

  帮助 / 提词器浮层全部浅色；不提供深色模式，系统切深色时 App 仍
  保持浅色且无「深底深字」区域。
- 底色与层级：窗口底 / 侧栏 / 卡片面为纸白，层级靠边框线（`#DCE9F3` /
  `#CFE3F2`）表达；次级面（分段控件底、输入区、预览画布）为浅蓝面
  `#F4FAFE`；选中行 / 选中条为选中面 `#EAF5FC` + 图谱蓝指示条。色值以
  `docs/design/DESIGN_SYSTEM.md` 为准。
- 暖色纪律：全 App 唯一暖色为陶橙 `#D97D3E`，只出现在「录制进行中」
  的状态点与计时（含 HUD 的「再按一次确认停止」）；警告三色
  （底 `#FFF9EC` / 边 `#EDD9A3` / 图标 `#C08F1D`）只出现在屏幕录制
  权限告示卡；其余任何界面（按钮、图标、徽标、编辑器警示标记）无暖色。
- 图标语言：各分区标题图标一律图谱蓝、SF Symbols 细线条权重；下拉箭头、
  展开箭头着蓝灰或图谱蓝；不出现 macOS 原生蓝色箭头。
- 警告只说一遍：无屏幕录制权限时，提示只保留来源预览上方告示卡一处；
  预览区只留「暂无可预览画面」一句短话；预览卡底部状态行显示来源摘要，
  不重复同一警告。
- 滑杆：拇指白面 + 图谱蓝描边；轨道底浅蓝线色、填充图谱蓝；禁用整体
  退灰 38%。
- 文案装饰清零：无全大写英文小标签；侧栏品牌区只写「八角录屏」与
  「为生活添点滋味」一句中文说明。
- 签名式结构只做一处：录制工作台「来源预览」为图鉴图版式样——外细
  内稍强双线框 + 左下角「来源预览 · 屏幕」小标牌；此外无其他装饰结构。
- 圆角与投影：卡片 12 / 主按钮 11 / 普通控件 8–9；投影只有一层极淡
  墨蓝影（toast 与 HUD 同一值），卡片不飘阴影。
- 布局红线：编辑器中间区 `layoutPriority(1)`、预览 160pt 保底、检查器
  右栏栏内滚动 + 分节折叠——窗口调到内容最小高度（实测 728pt）时预览 /
  时间线 / 检查器均在位；录制工作台右栏第一张卡片（来源）完整可见、
  无截断无滚动偏移（自动化由 `EditorLayoutTests` 回归）。
- 分段控件：自绘按钮组（`Design/StudioSegmented.swift`）选中段呈选中面
  浅蓝底 + 墨蓝字，与列表 / 侧栏选中同一口径；菜单式下拉仍保留系统控件、
  箭头着图谱蓝。
- 录制 HUD 与浮层（需真机录制复核）：浅色桌面与深色桌面壁纸上 HUD 胶囊
  均可读；录制中陶橙状态点 + 计时、暂停墨蓝点 + 「已暂停」、停止键
  墨蓝胶囊 + 陶橙方块图标；倒计时浮层为纸白圆 + 墨蓝数字；提词器浮层
  为纸白面板 + 墨蓝 / 蓝灰文字。
- HUD 可达性（需真机录制复核）：开启摄像头后 HUD 面板与内容同宽，「停止」
  按钮完整可见不被裁剪；HUD 与倒计时出现在**被录制屏幕**的顶部居中
  （录副屏时不在主屏）；拖动 HUD 胶囊无法拖出屏幕可见区。
- 录制状态页兜底（需真机录制复核）：录制中点 Dock 图标，主窗口弹回前台
  并显示状态页（计时 / 暂停 / 继续 / 标记 / 提词器 / 停止）；暂停后计时
  冻结、继续恢复；停止后进入编辑器；页面文案说明悬浮条与本窗口不会被
  录入；抽帧确认主窗口在录制中弹出也不进 `screen.mp4`。
- 菜单栏录制图标（需真机录制复核）：录制开始后菜单栏出现红色
  `record.circle` 图标，点按弹出「暂停录制 / 新标记 / 停止录制」；暂停后
  图标变灰、菜单首项变「继续录制」、标记置灰；停止 / 意外停止后图标消失；
  菜单操作时当前应用不失去焦点（图标不激活本 App）。
- App 图标与品牌线描 Logo：`Resources/AppIcon-1024.png` 生成各尺寸
  `.icns`；侧栏品牌区用 `Sources/AniseRecorder/Resources/anise-logo.png`；
  Dock 图标与侧栏 Logo 截图核对。

### 提词器浮窗与导出面板的画面级巡检

- 提词器浮窗：纸白面板 + 墨蓝/蓝灰文字；字号/速度控件行基线齐；
  预演徽标选中面浅蓝；滚动进度条图谱蓝；拖动面板位置后不遮 HUD。
- 导出面板：预设下拉箭头图谱蓝；分段导出「导出方式」选中面浅蓝；
  分辨率/帧率/编码选中段与周围卡片层级清晰；GIF 档位标签 11pt
  下限合规；导出进度行等宽数字不跳动。
- 两屏均不新增装饰动效；签名结构仍只有来源预览图版框一处。

### 快捷键帮助面板（需打包 App 人工验收）

- 菜单「帮助 > 键盘快捷键…」和 `⌘/` 都能打开面板；「关闭」按钮与
  Esc 均可关闭；已打开时再次触发只把面板带到前台，不叠加开窗。
- 面板内容与实际行为一致：`⌘N` 回到录制工作台；编辑器内空格 / I / O /
  M 生效、文本框输入时不触发；`←→↑↓` 仅画中画布局且选中摄像头时微调，
  按住 `⇧` 步进 5%；`⌘⌥` 系列随提词面板状态。
- 视觉：浅色 / 深色外观下分组标题、条目文字与按键胶囊对比清晰，
  无过小文字（<10pt）；面板窗口在常用屏幕尺寸下不遮挡主窗口操作。

### Esc 停止可选确认（需打包 App 人工验收）

- 默认关（现状不变）：设置「Esc 停止前需确认」默认关；录制中按一次
  `Esc` 或点「停止」立即停止，状态文案不出现确认提示。
- 开启后防误触：设置里打开开关再录一次；第一次按 `Esc` 或点「停止」不
  停止，HUD 状态文案位置显示「再按一次确认停止」；0.5 秒内再按一次才
  真正停止。
- 超时回退：第一次按后等约 1 秒（超过窗口）再按，只重新出现提示而不
  停止；不按键时提示自动消失、回到原状态文案。
- 提示不抢眼：确认提示沿用现有状态文案槽位（陶橙小字，录制期唯一暖色
  配额内），不遮挡计时、标记与其他按钮，布局无明显跳动。

### 录制来源

- 静态来源预览只在来源、显示器、窗口、区域变化或点“刷新来源”时更新，
  不持续截屏；无屏幕录制权限时给出降级提示，配置和启动按钮仍可操作。
- 屏幕录制权限预检引导卡（需 TCC + 打包 App）：
  `tccutil reset ScreenCapture com.localstudio.recorder` 后启动，来源预览
  上方出现「需要屏幕录制权限」引导卡 → 点「打开系统设置」跳到隐私与
  安全性的屏幕录制页 → 授权后回应用点「重新检查」，卡片消失并可正常
  录制；已授权时启动不出卡片。刚授权后预检可能短暂滞后，以「重新检查」
  为准。
- 窗口选择器按显示器分组，显示每屏窗口数量和所在显示器；搜索应用名、
  标题或显示器名均有效，选中项显示大图，取消不改变当前来源。
- 窗口清单默认包含所有 macOS 桌面（Space）的窗口：把目标窗口放到其他桌面
  或最小化后，停留当前桌面打开选择器，列表仍应出现该窗口并标注“当前不可见”；
  打开“仅当前桌面”后消失，关闭后恢复。选中其他桌面的窗口录制 10 秒，确认
  `screen.mp4` 包含该窗口画面；最小化窗口可能取不到画面，应给出明确错误。
- 整屏、窗口、区域三种来源都能开始和停止录制。
- 点击放大前置配置（需真机录制复核）：高级选项默认开启、停留 1.2 秒、
  倍率 1.65×；关闭开关后录制的新工程 `autoZoom == false`，预览 / 导出无
  点击放大；改停留 / 倍率后新工程 `zoomDuration / zoomScale` 与设置一致；
  开关只影响新录制，不改已打开的工程。
- 提词器（需解锁会话 + 打包 App）：
  - 整屏录制、面板打开：导出抽帧确认面板区域没有文字像素（自动化已在
    窗口服务器层断言不可共享，此条为画面级复核）。
  - 窗口录制、面板打开：同上；窗口选择器中不出现本应用的窗口。
  - 面板默认位置在摄像头悬浮窗上方、拖动顺滑、位置跨录制保留；字号 /
    速度 / 进度条 / 空格暂停 / 回到开头手感正常；录制中 HUD 提词按钮与
    `⌘⌥` 快捷键可用；预演徽标在非录制态显示。
  - 导入超过 1 MB 文稿给出明确提示；空文稿面板显示空状态。
  - 录制设置入口：冷启动进录制设置不滚动，第一屏「来源」卡片下方看到
    常展开的「提词器」卡片与「输入/粘贴文稿」「导入文件」按钮；点
    「输入/粘贴文稿」粘贴一段文字保存后开始录制，提词面板显示的正是
    这段文字；导入 `.md` 文件同样生效；清除文稿后录制，面板为空稿状态
    不报错。
- 开启摄像头后，倒计时和录制期间显示实时镜头悬浮窗；悬浮窗不进入
  `screen.mp4`，停止录制后工程初始构图与悬浮窗最后设置一致。
- 悬浮窗默认点击穿透；HUD“调整镜头”进入拖动 / 四角缩放 / 九宫格吸附，
  “完成”后恢复穿透，圆形 / 圆角切换在录制期间可见。
- 区域框选：拖拽创建后可拖动内部移动、拖四角 / 四边缩放；`Enter` 或双击
  确认，`Esc`、“取消”按钮、切换到其他 App 都能退出；重新框选带着上次
  区域，“清除区域”回到整屏；小于 64 × 64 时显示提示且确认按钮禁用；浮层
  打开时按 `⌘⇧R` 开始录制，浮层应先关闭。
- 多显示器下，主屏 / 副屏和负坐标屏幕的点击位置、裁剪区域正确。
- 1080p 和原始分辨率、30 / 60 fps 输出尺寸符合预期。
- 窗口关闭或权限不足时，错误提示明确且应用可恢复。

### 声音与摄像头

- 麦克风和系统声音可分别开启、关闭，导出后对应音轨存在或不存在。
- 麦克风菜单可选择“系统默认”和已连接输入设备；保存重开后选择保留，设备
  不可用时回落到系统默认。
- 同时录制时，人声和系统声音的相对时间正确，音量可接受。
- 连续暂停 / 继续 10 次后，成片没有黑帧、静音空洞或重复内容；暂停期间
  的鼠标移动和点击不进入成片，标记仍落在正确时间。
- 摄像头可与屏幕同时录制，开始时间偏移在合成后仍然对齐。
- 摄像头跨暂停 / 继续后仍对齐，停止后工程里只保留一个 `camera.mov`。
- 新录制可调整光标大小、平滑、静止隐藏和点击提示；关闭重绘后画面仍可正常
  导出，旧工程的光标仍在视频画面上。
- 只有点击摄像头区域才进入拖动；点击画布空白不会移动摄像头。
- 摄像头自由拖动、四角缩放、九宫格 / 边缘吸附、方向键微调、
  位置 / 大小数值输入和六个构图预设预览正确。
- 在播放头切换布局 / 显隐会生成新布局段；布局段起点可在时间线拖动并
  重新排序，0.3 / 0.5 / 0.8 秒过渡顺滑，删除布局段后回到上一段。
- 构图预设默认“从播放头生效”；已有布局段或播放头不在 0 秒时，预览仍
  立即切换，之前画面不变。“应用到全片”清除布局段后全片统一，⌘Z 恢复。
- 手动预设覆盖语音显隐 / 人脸自动段后再次运行自动生成，不覆盖用户选择；
  原始 `camera.mov` 保持不变。
- 一次拖动或缩放只占一个撤销步骤，保存重开后位置和大小保留。
- 摄像头在 16:9 和 9:16 画布中的位置与导出抽帧一致。
- 摄像头填满 / 完整显示、裁剪焦点、边框颜色 / 宽度和阴影在预览 / 导出中
  一致；关闭边框 / 阴影后不残留。
- 绿幕抠像开启后，纯绿区域露出画布，人物和衣物保持不透明；切换幕布颜色、
  容差、边缘柔化和去绿溢色时预览立即更新。
- 绿幕抠像下黑发、深色衣物与面部阴影保持不透明、颜色不发白不发灰（亮度
  权重只作用于背景键出，暗前景必须完整保留）；同时确认纯绿区域仍被抠干净。
- “从当前帧取色”在播放头对应摄像头帧上取样；无绿色幕布时给出明确提示，
  不会静默修改颜色或启用抠像。
- 绿幕开启时不显示摄像头圆角 / 形状遮罩、边框和矩形阴影；关闭后恢复原
  外观和画面。
- 使用真实绿色幕布和实际摄像头检查头发边缘、快速移动、阴影、半透明物体
  （另查边缘光包裹观感：人物边缘是否吃背景光、亮/暗背景下不违和；极暗
  发色/衣着在前景边缘是否完整保留——亮度硬门已放宽，需真人复核噪声）
  与绿色衣物反射；上述质量项不能只靠合成素材判定。
- 绿幕人工回归项：真实幕布下对比新旧键控观感（边缘是否还「突出」、
  阴影 / 亮斑区域是否干净、哑光内收 / 羽化观感）；三套预设
  在影棚 / 家用 / 阴影重幕下的实际效果；色场预览小图与重估入口是否
  能判断色场好坏；竖屏跟随在真人移动、多人入画、短暂出画时的取景
  观感与灵敏度三档差异；自动分割的真人 / 逆光 / 双人检出率、发丝
  边缘与背景模糊观感（合成素材无法判定真实检出率）。
- 点击缩放进入摄像头范围时，摄像头缩小并避开焦点；关闭避让后保持原位置，
  退出缩放后两种设置都能正确回位。
- 无摄像头或权限拒绝时，录屏仍能完成，并给出可见错误提示。
- 摄像头权限被拒后，录制工作台的“摄像头”开关保持开启、不被程序自动
  关闭；开关旁出现权限警示和“重新检查”按钮。
- 在“系统设置 › 隐私与安全性 › 相机”里允许后点“重新检查”，警示消失、
  摄像头预览恢复。
- 权限被拒状态下直接开始录制，成片为纯屏录制（无摄像头画面），错误
  提示可见且应用状态可恢复正常。
- 多显示器下主屏与负坐标副屏的窗口移动、缩放和点击映射正确。

### 编辑与导出

- 默认 `1220 × 800` 和最小 `1060 × 700` 下滚动摄像头、剪辑、精剪和字幕
  页，左侧预览与时间线始终固定；检查器页签栏始终在顶部。
- 摄像头页默认位置能直接看到“绿幕抠像”标题；展开后无需整页滚动也不会
  丢失左侧工作区。折叠标题在收起时仍显示关键摘要。
- 分别点击视频、摄像头、缩放、声音轨道，一次到达正确页签和分组；轨道
  按钮可用键盘聚焦，当前入口有高亮。
- 检查器页签折叠组只在本次运行保留，退出并重启后恢复默认展开项；左栏
  228px / 56px 折叠状态跨启动保留（`@AppStorage`，代码依据
  `RootView.swift` 的 `sidebarCollapsed`）。
- 入点 / 出点不能交叉，播放会在出点停止。
- 视频片段可切分、删除、边缘拖动修剪和切换 0.25×–4×；变速后画面、
  摄像头、点击缩放和音频保持同步。
- 手动缩放区可添加、启停、调倍率 / 时长 / 焦点；手动区优先于点击建议。
- 空格播放 / 暂停，`I` / `O` 在非文本输入状态下设置首段入点和末段出点。
- 麦克风 / 系统声音增益与静音在预览、保存重开和导出后一致；波形可见。

### 持久化

- 修改工程后切换项目、退出并重开，设置仍然保留。
- 重新构建后，已有工程仍可读取；旧 Schema 工程会迁移到 Schema 5。
- 连续撤销 / 重做 20 次后，片段、布局段、缩放区和音频参数不丢失。
- 人为破坏主 `project.json` 后，应用从 `project.previous.json` 恢复并显示提示。
- 背景图片、缩略图和摄像头文件缺失时，应用不应崩溃。
- 录制中强制退出后重开应用，已落盘视频和已有音频恢复为“（已恢复）”工程；
  正常停止后不残留恢复清单。

### 工程管理

- 工程右键显示“在访达中显示 / 从列表移除 / 归档 / 删除工程和原视频…”，
  导出中或录制准备 / 录制期间相应动作禁用。
- “从列表移除”后 `project.json`、`screen.mp4`、摄像头和声音文件仍在；
  开启设置“显示已移除工程”后可恢复。
- “归档”后完整目录位于 `~/Movies/八角录屏/Archive/`，侧栏不再显示；
  `文件 > 导入工程…` 可恢复并重新打开，源目录在成功导入后移除。
- “删除工程和原视频…”始终显示二次确认；确认后整个目录进入废纸篓，目录外
  的成片不受影响。取消、非法路径、目录不存在或移动失败时原工程仍可恢复。
- 设置窗口（`⌘,`）：Delete 键默认动作三档可选且“删除工程和原视频…”不在

### 字幕与离线识别

- “本机生成”先请求语音识别权限；拒绝后给出明确提示，不崩溃、不联网。
- 系统或当前语言没有本机模型时，按钮流程明确失败并建议 SRT 导入。
- 本机识别音频使用工程裁剪、ripple 和变速后的时间；生成后字幕可校对。
- 有手动字幕时再次生成会先确认替换，取消后原字幕不变，替换后可撤销。
- 断网执行 SRT 导入、编辑、烧录、SRT 和章节导出，所有流程正常工作。
