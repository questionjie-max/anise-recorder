# 路线图

方向性计划，不含具体时间承诺。功能清单与当前边界见
[FEATURES.md](FEATURES.md)；欢迎通过 Issue 讨论优先级。

## 产品红线（不会做的）

- 任何需要联网、上传、云同步或账号的功能（local-first 是产品立场）
- 录制内容之外的数据收集（遥测、分析、崩溃上报）
- 违背“录什么存什么”的隐藏行为

## 方向性计划

- **绿幕质量深化**：真实幕布下的边缘质量（发丝、光照不均、绿溢色）继续
  用滑杆参数打磨；欢迎提交真实场景的对比样本与参数组合。
- **深色模式**：当前锁定浅色「图谱蓝线描」。深色令牌需要完整推导一套
  语义色值，列入长期方向，优先级低于功能类反馈。
- **iPhone / iPad 连续互通画面采集**：把 iOS 设备屏幕作为第三种录制来源
  （macOS Sequoia 提供的系统能力），尚在调研。
- **MP4 容器章节**：章节目前导出为独立文本文件；MP4 容器内写 text 轨受
  AVFoundation 公开 API 限制，等待可行方案。
- **精剪语义层**：当前口头禅建议只处理“整条字幕为填充词”；长句中间的
  语义级改稿不做自动剪切，只会以建议形式呈现。
- **导出格式扩展**：WebM / ProRes 等按需求热度评估。

## 已知限制

见 [FEATURES.md](FEATURES.md) 的「当前边界」一节，包括：自动放大只针对
左键点击、本机字幕依赖系统语言包、精剪候选是会话数据、系统壁纸为静态
快照、录制期悬浮窗首版只支持画中画等。
