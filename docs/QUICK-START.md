# 八角录屏 · 快速上手（一页纸）

**录**

1. 打开八角录屏 → 右侧选来源（屏幕 / 窗口 / 区域）。
2. 需要出镜就打开摄像头；需要讲稿就在「提词器」卡片点「输入/粘贴文稿」或「导入文件」。
3. 点「开始录制」，倒计时 3 秒后开录。录完点 HUD 的「停止」。

**剪**

1. 录制完成自动进入编辑器。点时间线里的视频片段，调入出点、速度。
2. 想强调操作就检查「点击放大」；想出镜讲解就调摄像头布局。
3. 字幕页点「本机生成」出一版草稿，逐条校对（清空一条会删除整条，首次会二次确认）。

**出**

1. 导出页选分辨率（默认 1080p60）。
2. 点「导出 MP4」→ 选保存位置。成片和 SRT 字幕都在你选的文件夹里。
3. 要动图就展开「GIF 导出」。

**快捷键**：`⌘N` 新建录制 · `空格` 播放/暂停 · `M` 打标记 ·
`I`/`O` 设入出点 · `⌘B` 播放头切分 · `⌘Z` 撤销 · `⌘\` 折叠/展开时间线 · `Esc` 停止录制。
